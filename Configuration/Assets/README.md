# 云写君应用图标

`AppIcon.png` 是内置 imagegen 工具生成的透明背景原图；`AppIcon.icns` 是 macOS 原生 `sips` 缩放、`iconutil` 打包的应用图标，包含 16–1024 像素规格。构建脚本将其复制到应用包 Resources，Info.plist 的 CFBundleIconFile 引用 AppIcon。菜单栏继续使用原生单色波形，避免彩色图案在小尺寸下难以辨认。

生成提示词：为云写君语音转结构化文字应用设计一个正面 macOS 图标，圆角方形占画面约 82%，周围透明。深靛蓝到柔和蓝紫渐变底，白色云形融合三条粗声波与两条文字线条，简洁、柔和立体感，小尺寸清晰。无文字、无水印、无设备模型、无透视。

更新后需退出应用再运行 `./Scripts/run-app.sh --rebuild`。本地临时签名仍可能影响原有系统授权；仅更换图标不改变数据标识和 API 配置。
