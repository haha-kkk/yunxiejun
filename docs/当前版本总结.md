## 1. 已实现的功能

本轮新增：

- 对外名称、Swift 包及可执行产品统一为“云写君”。内部模块、Bundle ID、钥匙串服务及数据库路径保留旧标识。
- 主语音流程默认开启“兼容输入（临时使用剪贴板）”，可关闭后使用原 AX 写入。输出前选择单一路径，只发送一次粘贴，不自动发送消息、不在失败后换路重试。保留完整剪贴板项目与格式，遇到外部更新不覆盖；无法恢复或确认时提示用户先检查目标。
- 源码新增 `cleanup-diagnostics` 日志：只记录固定阶段、单调时钟耗时、本地 UUID 和 HTTP 状态。不含正文、音频、词条、凭据、请求头、URL 或错误详情。当前运行版尚不含此新增日志。

既有功能（下面的早期验收记录不等于本轮复测）：

- 菜单栏“波形＋云写君”入口、主窗口及设置窗口。
- Fn 开始真实录音，再按 Fn 结束；录音、Thinking 状态浮窗不抢输入焦点。正式录音每段最多三分钟，五秒按钮仅用于诊断。
- 麦克风音频转写，再调用模型去口头语、重复并整理表达。
- 长内容按并列事项编号分点，保留说明、限制、原有开头及收尾，不生成压缩摘要。两段真实 API 样本已验收，其中一段约 800 字、五要点；相关离线回归 26 项通过。
- 向处理完成时的聚焦输入框写入文字，不自动发送消息。原文档记载过 TextEdit 实体 Fn 短录音验收；本轮只验证按钮录音到 TextEdit 自动入框，不能据此重申实体 Fn 已复测。
- 无法直接输入时显示结果及原因；点击“复制”才更新剪贴板。结果浮窗十分钟关闭，已保存结果可在本机归档找回。
- 录音和处理中按 Esc 取消，阻止迟到结果输出，并清理本次临时录音。
- 设置词典支持手动新增、搜索、来源分类、编辑、删除及撤销；词条提供给识别与整理接口。
- API 密钥存放在 macOS 钥匙串；词典、归档和纠正计数使用本机 SQLite。

证据边界：长结构化已验证真实文本整理接口，不是用预写结果模拟成功；但这次输入是开发口述文本，不是用户本人连续三分钟录音。原文与结果见[长口述结构化真实结果](./长口述结构化真实结果.md)，测试详情见[长口述结构化验收](./长口述结构化验收.md)。

## 3. 怎么运行

需要 macOS 14 或更新版本及 Apple Command Line Tools。测试建议 Swift 6 或更新版本，本机已使用 Swift 6.1.2。无需安装第三方 Swift 包。

检查工具：

```sh
swift --version
xcode-select -p
```

未安装开发工具时运行 `xcode-select --install`，在系统窗口完成安装。日常启动：

```sh
cd /Users/apple/Downloads/typeless
./Scripts/run-app.sh
```

脚本会打开 `.build/云写君.app`；应看到“云写君 · 语音输入”窗口及菜单栏“波形＋云写君”。已有应用包时不会重新签名；应用已运行时只唤回窗口。

首次或授权失效时：

1. 设置 →“API 与快捷键”：确认北京地域百炼密钥显示已配置。已有密钥无需重复保存，不要把密钥提交进 Git。
2. macOS 系统设置 → 隐私与安全性：麦克风用于录音，输入监控用于全局 Fn／Esc，辅助功能用于外部输入框访问。这三项互不替代。
3. 本机 Fn 系统动作应为“不执行任何操作”，避免同时切换输入法。此前已获用户授权改过此项，不必每次重复修改。
4. 应用点“开启 Fn 监听”，应看到“正在监听 Fn / Esc”。若仍提示未授权，系统开关显示开启也不证明当前签名有效，需要刷新本应用授权并退出重开；身份验证只能由用户本人完成。
5. TextEdit 新建空白文稿并点击正文，Fn 开始口述、Fn 结束，等 Thinking 消失，文字应直接出现。无可用输入框则出现复制结果浮窗；录音或处理中按 Esc 应取消。

修改代码后，先在本应用菜单中退出，再运行：

```sh
cd /Users/apple/Downloads/typeless
./Scripts/run-app.sh --rebuild
```

如果没有退出，脚本只打开旧进程，不会更新正在运行的版本。不要同时用 `swift run` 和应用包启动多份进程。

## 4. 后续修改特别注意

- **临时签名与权限是目前最大运行坑。** `run-app.sh` 使用本地临时签名；重新构建可能让旧授权失效。普通启动不加 `--rebuild`。后续稳定交付应使用合适的固定开发／发布签名流程并实测升级授权，不能承诺换签名就一定永不询问。
- **共享整理规则只改一处。** `TextCleanupPrompt.swift` 同时用于 Fn 主流程和整理页。不要在某个页面另写一套提示词；修改后用原始文本对照真实模型输出，尤其检查否定、金额和收尾。
- **长内容存在多层上限。** 录音三分钟，整理输入 16 KiB，输出 32 KiB，生成上限 4096 tokens。请求配置 45 秒，共用网络层另有 90 秒请求与 180 秒资源限制；整理页总期限 75 秒，主语音流程识别与整理各 180 秒。它们不是同一层超时。以后扩大长度，要一起检查音频／请求大小、截断与超时，不能只改录音时长。服务限制需要重新查官方资料。
- **会话取消要保持编号校验。** `DictationController.swift` 用会话编号拒绝迟到结果。不能让新异步任务绕过校验直接写输入框、弹结果或保存归档，否则 Esc 后可能补出文字。已经写入的文字不能靠取消撤回。
- **外部输入框不是普通文本框。** `FocusedTextOutput.swift` 依赖 macOS 辅助功能；应用切换、光标变化和不可读输入框都会影响结果。写入失败应保留可复制文本，不要盲目重试造成重复输入。
- **自动学习仍是待修模块。** `ExternalTextProbeController.swift`、`StableTermCorrection.swift` 和 `CorrectionLearningController.swift` 涉及读取外部原文、稳定改词检测和计数。之前连带空格变化已修，但实机入口未通过。后续应先检查实际读取和计数，再检查确认弹窗；不以数据库模拟三次通过代替原输入框实测。
- **词典提示不是硬替换。** 不要把所有 cloud 直接替换为 Claude，云服务、代码路径等场景会被误改。
- **保护本地数据。** 不要为调试删除用户词典或归档；数据库结构修改要考虑旧数据。临时录音用于处理后清理，目前不是音频历史功能。
- **真实 API 测试会收费。** 普通回归不应调用 API；长文本真实测试必须显式开启，读取已有钥匙串，不打印或保存密钥。
- **旧说明按时间看。** README 中 T03–T23 是历史独立验收，一些“模拟／未接通”描述不代表最新主流程；这份总结记录当前可用程度，不把已有代码等同全部实测通过。

整理相关离线检查：


真实结构化复测（调用两次百炼 API）：

