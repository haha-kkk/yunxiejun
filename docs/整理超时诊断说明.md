# 整理超时阶段诊断

仅源码补丁；未部署、重签或调用真实 API，当前运行版不包含这些日志。

日志 subsystem 为 `local.typeless01.app`，category 为 `cleanup-diagnostics`。
每次整理生成本地 UUID，只记录固定阶段、单调时钟耗时（毫秒）及收到的 HTTP 状态码。
不记录正文、音频、词条、凭据、请求或响应头、URL、错误详情；没有日志导出或上传。

阶段：started → vocabularyFinished → keychainStarted → keychainFinished → networkStarted → httpReceived → bodyFinished → completed。
失败记录 failed；任务取消会立即记录 cancellationRequested（不代表同步钥匙串调用已中断）。
取消后即使内部调用迟到返回，也不能交出成功结果。收到非 200 HTTP 状态时不读取错误正文，因此没有 bodyFinished。

最后一个阶段可缩小等待范围，但不能凭阶段日志判断服务端是否计费或直接确定根因。
75 秒仍是 UI 总期限，本补丁不改变超时、提示词或输出行为。

离线测试采用虚构密钥和 URLProtocol 隔离响应，不联网、不访问钥匙串。
后续需另行部署确认；一次有界合成文字测试足以收集阶段证据，不需要重新录音。
