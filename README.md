# 桌面语音输入工具（云写君）

2026-10-02 命名统一：产品、Swift 包与可执行产物均为“云写君”。内部模块、应用标识、钥匙串和数据目录保留兼容旧值，不迁移数据。本文历史操作中的产品显示名已统一，历史验收结果不变。当前运行应用尚未替换；重新构建的临时签名仍可能要求刷新系统授权。

当前版本功能、限制、启动与维护注意事项见 [当前版本总结](docs/当前版本总结.md)。三次改词自动学习实机尚未通过，已按用户决定延期；下文涉及该功能的代码流程说明不代表可用性验收完成。

当前沿用 Swift、AppKit 和 SwiftUI 原生 macOS 路线。2026-10-01 已接通真实主流程：**Fn 开始录音 → Fn 结束 → 百炼语音识别 → 带词典整理 → 写入最终光标位置**，Esc 取消未完成会话。成功写入后会观察原输入框最多 60 秒，稳定纠词累计三次后询问是否加入词典。

第一次完整试用，请按 [核心流程端到端验收](docs/核心流程端到端验收.md) 操作。当前正式语音输入每段最多 3 分钟，独立录音诊断仍为 5 秒；无可用输入框或无法确认写入时，弹出“复制最后的转录”，点击“复制”才写入剪贴板，首页也保留完整结果。浮窗 10 分钟后关闭，已完成的整理结果保存在本机归档，退出重开仍可找回。Chrome 某些输入框仍不支持直接写入；识别和术语修正效果需用实际口述核对。

## 在终端运行

```sh
cd /Users/apple/Downloads/typeless
./Scripts/run-app.sh
```

首次运行时脚本会构建项目，在 `.build/云写君.app` 中生成本地应用，绑定应用标识完成本地临时签名并校验后打开。以后不带参数运行会直接启动这份已签名应用，不重新构建或签名，避免每次启动都触发 macOS 重新授权。修改代码后，先从应用菜单退出，再运行 `./Scripts/run-app.sh --rebuild` 加载新版本；重新构建并临时签名仍可能需要重新授权。若应用已经运行，脚本只唤回已有窗口；终端命令结束后，应用仍会运行。

运行后应出现“云写君 · 语音输入”窗口，屏幕右上方菜单栏入口是“波形图标＋云写君”。点击该入口可打开验证窗口、打开设置、开始/停止 Fn 监听或退出。

在应用处于前台时，屏幕左上方的“云写君”菜单也有“打开语音输入窗口”和“设置…”入口。设置首次打开默认显示“词典”标签；“API 与快捷键”标签提供百炼北京 API 密钥的保存、替换、删除，以及 Fn 使用规则。查看词典和保存密钥都不会调用 API。关闭窗口只隐藏窗口；点击 Dock 中的应用或菜单中的“打开语音输入窗口”可以再次打开。

请勿同时用 `swift run` 和启动脚本运行多份应用，以免出现两个版本的菜单栏入口。

## 当前的日常使用

1. 运行后停在“语音输入”页，点“开启 Fn 监听”，应显示“正在监听 Fn / Esc”。
2. 先在 TextEdit 新建文稿并点击正文，按下并松开 Fn，说一句话，再按下并松开 Fn。
3. 等待录音浮窗变为 Thinking、随后消失。整理结果应进入光标处，不自动发送消息。
4. 不能写入时，在“复制最后的转录”浮窗查看原因和完整结果，点“复制”后到目标处粘贴。关闭浮窗后，可点击首页“打开归档”，也可用“波形＋云写君 → 归档…”找回。
5. 录音或处理中按 Esc 取消。详细验收、权限恢复、词典和异常路径见上面的端到端清单。

顶部空间不足时，旧验证页面会收进工具栏的“更多项目”按钮。以下 T03–T23 内容是**各模块的历史独立验收记录**；其中“Fn 仍模拟”“尚未接通”等描述对应当时版本，不代表现在的主流程。五秒录音测试仍是独立入口，日常使用请在“语音输入”页操作。

| 异常退出清理 | 正常录完；在访达按 Shift+Command+G，输入终端 `getconf DARWIN_USER_TEMP_DIR` 输出的路径，进入 `Typeless01-recordings-v1` 并记下当前目录；用苹果菜单“强制退出”仅退出本应用，然后重开 | 上次目录已被清理，页面回到尚未录音；其他目录不受影响。此步骤会丢弃测试录音 |
| 文档与实际功能一致 | 对照 Fn 页与麦克风录音页 | Fn 页明确是模拟，录音页是真实录音；两者尚未接通 |

播放启动失败、损坏文件、无结束回调、迟到回调及清理权限异常已有隔离自动测试；无需为手动复测破坏系统文件或强行制造磁盘故障。

启动脚本只把可执行文件的运行映射视为应用正在运行，系统权限进程 `tccd` 仅打开文件不会再阻止重建。
